## 4. Resource & Process Governance Controls

1. **Least-Privilege Execution (Non-Root)**:
   The container does NOT execute as `root`. A dedicated unprivileged user (`appuser`, UID `10001`) and group (`appgroup`, GID `10001`) are provisioned during build. All application files and execution rights are bound exclusively to this unprivileged UID.
2. **Memory Hard Limit**:
   Configured with `--memory=1024m` and `--memory-swap=1024m`. Any process attempting memory exhaustion or memory bomb attacks is immediately terminated by the Linux OOM-killer without degrading host performance.
3. **CPU Allocation**:
   Configured with `--cpus=1.0`. Prevents runaway compute consumption or cryptographic mining attacks.
4. **PID Hard Ceiling**:
   Configured with `--pids-limit=100` to mitigate fork-bomb exploits or unbounded sub-process spawning.
5. **Watchdog & Timeout Controls**:
   The evaluation adapter maintains a hard timeout of `30.0` seconds per test invocation. Any hung or blocking inference loop is aborted with a timeout response.

---

## 5. Network Boundaries & Secret Protection

1. **Network Egress**:
   The sandbox binds to `127.0.0.1:8000` on the local loopback interface. In offline evaluation mode, target LLM calls default to the internal `MockLLMProvider`, eliminating external network transmission entirely.
2. **Secret Redaction**:
   All audit logs generated by the target application and QualiTrust AI adapters pass through `logging_utils.redact_secrets()`, ensuring no API tokens, JWTs, or environment variables are stored in execution traces or evaluation deliverables.
